## Participant questionnaire

Rate each statement from 1 (strongly disagree) to 5 (strongly agree).

1. Registration instructions were clear.
2. I understood that administrator approval was required.
3. The dashboard was easy to understand.
4. I could find my assigned department.
5. Navigation labels were clear.
6. Switching between Arabic and English worked as expected.
7. The interface felt consistent.
8. I would feel confident using the application after brief training.

Severity guidance:

- **Low:** cosmetic issue or minor inconvenience.
- **Medium:** task remains possible but requires help or a workaround.
- **High:** task cannot be completed or information is misleading.
- **Critical:** privacy, security, data-loss, or cross-user access failure; stop testing.
